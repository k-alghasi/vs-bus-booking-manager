سیستم رزرواسیون صندلی اتوبوس با انتخاب گرافیکی، زمان‌بندی سفر و بلیط الکترونیکی برای ووکامرس.

== Description ==

VS Bus Booking Manager یک سیستم کامل رزرو بلیط اتوبوس برای وردپرس و ووکامرس است. با این افزونه می‌توانید صندلی‌های اتوبوس را به‌صورت گرافیکی طراحی کنید، سفرهای روزانه/هفتگی/تاریخ خاص تعریف کنید، و بلیط الکترونیکی با QR Code صادر کنید.

= ویژگی‌های کلیدی =

* **انتخاب گرافیکی صندلی:** نقشه تعاملی صندلی‌ها با راهروی وسط و نمایش لحظه‌ای وضعیت رزرو
* **ویرایشگر بصری صندلی‌ها:** طراحی چیدمان اتوبوس (استاندارد ۲×۲، VIP ۱×۲، لوکس ۱×۱) با کلیک و درگ
* **زمان‌بندی سفر:** پشتیبانی از سفرهای روزانه، هفتگی، یا تاریخ خاص
* **بلیط الکترونیکی:** تولید QR Code و نمایش بلیط در صفحه حساب کاربری
* **لیست سیاه مسافران:** جلوگیری از رزرو کاربران مشکوک بر اساس کد ملی
* **اعتبارسنجی کد ملی ایرانی:** الگوریتم کنترل رقم کد ملی
* **فیلدهای پویای مسافر:** تعریف فیلدهای دلخواه (نام، کد ملی، تلفن، و...)
* **ادغام کامل ووکامرس:** استفاده از سبد خرید و درگاه‌های پرداخت ووکامرس
* **ویجت المنتور:** نمایش فرم رزرو در صفحات ساخته‌شده با المنتور
* **داشبورد مدیریتی:** نمودارهای فروش و آمار بلیط
* **سیستم ایمیل:** اطلاع‌رسانی خودکار به مشتری و مدیر
* **کش چندلایه:** Object Cache + Transients برای کارایی بالا
* **REST API:** برای اپلیکیشن موبایل (نیازمند نسخه Pro)
* **پشتیبانی از RTL:** کاملاً راست‌چین و فارسی

برای قابلیت‌های پیشرفته (SMS، اسکنر بلیط، PDF با لوگو، گزارش‌گیری پیشرفته) نسخه Pro را دریافت کنید:
https://vernasoft.ir

== Installation ==

1. فایل‌های افزونه را در مسیر `/wp-content/plugins/vs-bus-booking-manager/` آپلود کنید.
2. افزونه را از منوی «افزونه‌ها» در وردپرس فعال کنید.
3. مطمئن شوید ووکامرس نصب و فعال است.
4. به ویرایش محصول → بخش «Bus Seat Booking» بروید و رزرو صندلی را فعال کنید.
5. در تب «Visual Seat Editor» چیدمان صندلی‌ها را طراحی کنید.
6. در تب «Trip Schedule» زمان‌بندی سفر را تنظیم کنید.
7. فیلدهای مسافر را از منوی «Bus Booking → Passenger Fields» پیکربندی کنید.

== Frequently Asked Questions ==

= آیا این افزونه به ووکامرس نیاز دارد؟ =
بله، ووکامرس برای پردازش پرداخت و مدیریت سفارشات لازم است.

= آیا می‌توانم سفرهای روزانه تعریف کنم؟ =
بله، از سه نوع زمان‌بندی پشتیبانی می‌شود: روزانه، هفتگی (روزهای خاص)، و تاریخ خاص.

= آیا کد ملی ایرانی اعتبارسنجی می‌شود؟ =
بله، الگوریتم کنترل رقم کد ملی ایرانی پیاده‌سازی شده است.

= چگونه صندلی‌های غیرقابل رزرو (مثل جای راننده) را مشخص کنم؟ =
در Visual Seat Editor روی صندلی مورد نظر کلیک کنید تا غیرفعال شود. جای خالی در نقشه نمایش داده می‌شود.

= آیا از RTL پشتیبانی می‌کند؟ =
بله، افزونه کاملاً راست‌چین و فارسی است.

= چگونه نسخه Pro را دریافت کنم؟ =
از سایت https://vernasoft.ir نسخه Pro را تهیه کنید.
